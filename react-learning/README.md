## 🚀 Getting Started

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/)
- npm, which comes with Node.js
- A code editor such as Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/Trusha-Bhardava/react-learning-concept-question.git
```

### 2. Navigate to the Project

```bash
cd react-learning-concept-question
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Vite will display a local URL in the terminal. Open that URL in your browser to view the application.

## 💡 How to Use This Repository

1. Open the `src` folder.
2. Explore the available React components and example files.
3. Read the code and comments carefully.
4. Run the application and observe the result.
5. Modify the code to understand how each concept works.
6. Practice implementing the same concept independently.
7. Review errors and learn how to debug them.

## 🧠 Learning Approach

My approach is to learn React by understanding the code rather than only copying it.

For each concept, the goal is to understand:

- What the concept means.
- Why it is used.
- How it works in a React application.
- How to implement it with a practical example.
- What common mistakes to avoid.
